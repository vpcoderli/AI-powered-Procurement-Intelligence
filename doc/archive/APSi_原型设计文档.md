# APSi 原型设计文档 (MVP 阶段)

## 1. 设计概述

本文档用于描述 APSi 平台在 MVP 阶段的核心前端页面布局、信息架构及用户交互流程。设计原则以“**效率优先、信息密集、操作极简**”为核心，帮助供应商快速定位目标招标信息。

---

## 2. 信息架构 (Site Map)

```text
[APSi 门户]
 ├── [登录/注册页]
 ├── [主仪表板 - 统一搜索工作台]
 │    ├── 顶部导航栏 (Logo, 搜索框, 用户头像/设置)
 │    ├── 左侧侧边栏 (筛选器：州、日期、机构)
 │    └── 主内容区 (招标列表)
 ├── [招标详情页]
 │    ├── 基本信息区 (标题、金额、截止日期、联系方式)
 │    ├── 详细描述区 (文本详情)
 │    └── 附件与操作区 (下载链接、原始来源、收藏按钮)
 └── [我的收藏页]
      └── 已保存的招标列表
```

## 3. 核心页面设计与交互

### 3.1 登录与注册页 (Login / Sign Up)
- **布局**：居中卡片式设计。
- **元素**：
  - **Logo**：顶部居中展示 APSi Logo。
  - **输入框**：邮箱 (Email)、密码 (Password)。
  - **按钮**：登录 (Log In) / 注册 (Sign Up)。
  - **链接**：忘记密码 (Forgot Password?)。
- **交互**：
  - 邮箱格式和密码强度的实时校验。
  - 登录成功后，跳转至**主仪表板**。

### 3.2 主仪表板 - 统一搜索工作台 (Dashboard / Bid Search)
这是平台的核心页面，采用经典的“左侧筛选 + 右侧列表”布局。

#### 3.2.1 顶部导航栏 (Header)
- **左侧**：APSi Logo (点击返回首页)。
- **中间**：全局全文搜索框 (Global Search Bar)，支持输入关键字（如 "IT Services", "Food Delivery"），并带有“搜索”按钮。
- **右侧**：当前用户头像/名称下拉菜单（包含：我的收藏、账户设置、退出登录）。

#### 3.2.2 左侧筛选栏 (Filters Sidebar)
- **地区 (State/Region)**：
  - 多选复选框列表（例如：[ ] All States, [ ] Federal (SAM.gov), [ ] CA, [ ] TX, [ ] NY... 等 50 州）。
  - 支持首字母快速搜索州名。
- **截止日期 (Deadline)**：
  - 单选按钮组：Any time, Next 7 days, Next 30 days, Custom Range (提供日期选择器)。
- **发布日期 (Published Date)**：
  - 单选按钮组：Any time, Last 24 hours, Last 7 days, Custom Range。

#### 3.2.3 主内容区 - 招标列表 (Bid List)
- **顶部信息**：显示当前搜索条件下的“总结果数”及排序方式下拉框（Sort by: Newest, Deadline, Relevance）。
- **列表卡片 (Bid Card)**：每条招标信息为一个卡片。
  - **标题 (Title)**：大字号，加粗（点击跳转详情页）。
  - **来源徽章 (Source Badge)**：显示该招标来自哪个州或机构（例如：[SAM.gov]、[State of CA]）。
  - **摘要 (Snippet)**：截取描述的前 2-3 行。
  - **关键元数据**：
    - 截止日期 (Deadline: MM/DD/YYYY)
    - 发布日期 (Posted: MM/DD/YYYY)
  - **操作**：卡片右上角有一个“收藏”图标（空心星形/实心星形）。
- **底部**：分页控件 (Pagination)。

### 3.3 招标详情页 (Bid Details Page)
- **交互模式**：可以是在当前列表页弹出的侧边抽屉 (Side Drawer)，或是独立的新页面。为承载更多信息，建议采用**新页面或全屏模态框**。
- **页面布局**：
  - **顶部标题区**：
    - 包含返回列表的按钮（< Back to Results）。
    - 醒目的招标标题。
    - 两个核心按钮：**[Save / 收藏]** 和 **[View Original Source / 查看原文]**（在新标签页打开）。
  - **核心元数据区 (Metadata)**：
    - 采用网格布局展示：
      - Agency / Issuer (发布机构)
      - Source (数据源)
      - Published Date (发布日期)
      - Deadline Date (截止日期)
      - Estimated Amount (预估金额，若有)
  - **详细描述区 (Description)**：
    - 占据页面主体，展示抓取到的完整招标说明（支持基础 Markdown 或保留换行格式）。
  - **附件区 (Attachments)**：
    - 列表展示抓取到的附件链接（如：Document 1.pdf, Specifications.xlsx）。
    - 点击直接触发下载或跳转至源站对应的下载页面。

### 3.4 我的收藏页 (Saved Bids)
- **布局**：与主仪表板的右侧列表区一致，去掉了左侧的全局筛选栏。
- **内容**：展示用户标记为“已收藏”的所有招标卡片。
- **交互**：支持在卡片上直接点击“取消收藏”，卡片随即从列表中移除。

## 4. UI/UX 设计规范 (建议)
- **色彩主题**：
  - 主色调：沉稳、专业的企业蓝 (Corporate Blue) 或深青色，传达 B2B 产品的信任感。
  - 背景色：浅灰白 (Light Gray)，使得白色卡片内容更为突出。
  - 强调色：橙色或绿色，用于“截止日期临近”等重要提示。
- **字体排版**：
  - 使用无衬线字体（如 Inter, Roboto, 或 system-ui），确保大量文本阅读时的清晰度。
- **响应式设计**：
  - MVP 优先保证桌面端 (Desktop) 的使用体验（供应商通常在电脑前办公）。
  - 移动端 (Mobile) 提供基础的列表查看能力即可，不作为 MVP 的重点。

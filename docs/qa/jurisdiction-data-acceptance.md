# 州、市、县／郡数据测试验收要求

本要求适用于每次项目测试及其报告。代码用例通过与真实业务数据验收必须分别记录；只有以下数据检查全部有有效证据，才能声明相应范围的数据完整可靠、整体数据质量验收通过。

## 覆盖范围与统计口径

- 每次先记录数据库／环境、测试时间、来源清单、目标机构清单和数据时间范围。按州、市、县／郡分别列出目标数、实际验证数、缺失数、部分结果数、未验证数及对应来源 ID。
- 本项目 `state` 为州级、`city` 为市级、`county` 为县／郡级。县和郡是本项目 county 的两种中文称呼，不能重复计数或虚构两个独立覆盖层级。已有 township、special_district、federal 来源仍须按其真实类型记录，不能混入州、市、county 以补足数量。
- 全国州级范围沿用项目 50 州清单；地方范围必须有明确、可核对的目标辖区及来源清单。清单尚未明确或无法核对时，结果为“范围未确认／未验证”，不能宣称地方或全国数据完整。
- 使用既定业务覆盖清单作为分母。不能只统计抓取成功的来源、排除失败来源，或以抽样／少量 seed 代表全部辖区。任何范围变更必须在报告中显式说明。
- “已注册来源”“抓取成功”“有招标记录”“数据完整且可用”分别统计；前一项不能作为后一项的证明。

## 每个层级必须验证的内容

| 验证项 | 必须具备的证据与判定 |
| --- | --- |
| 来源可靠、辖区正确 | 官方或经核验的授权发布来源；记录来源 URL、核验时间、来源／租户 ID；州码、辖区类型及适用的 FIPS/GEOID 一致，无跨州、同名县市或跨租户混入 |
| 列表完整 | 指定时间和状态范围内的所有分页／游标／列表类型已覆盖；保留上游总数或可靠的结束证据、唯一 ID 对账和停止原因；预算耗尽、WAF、超时、重复页或未知结束不能算完整 |
| 招标字段完整 | 标题、发布机构、辖区、原始公告 URL、状态和适用日期有效；核验正文、联系人及业务所需字段；上游未提供的字段如实标注并保留依据，不能用占位文字补齐 |
| 正文真实可用 | 与原始项目一致，具有有效采购内容；登录页、验证码页、错误页、列表摘要不能充当详情正文；分析资格遵循既有语义质量门禁，不能只看长度 |
| 附件完整且属于本项目 | 对照上游公开文件清单；实际下载并验证类型、非空内容及项目归属；登录页／HTML 错误响应／跨项目附件不算有效；没有可信完整清单时，只报已发现及已验证数 |
| 时效与生命周期 | 按来源既定时效要求核验抓取／验证时间、截止时间、状态及修订；复用旧正文保留旧验证时间；仅完整且可靠的列表扫描允许推断未出现记录已下架 |
| 导入与展示一致 | 核验规范化、补全、SQLite/MySQL 导入、重新导入、API、搜索及详情展示；保留字段 provenance 和有效历史内容，无丢失、重复、串源或未知状态被展示成成功 |
| 缺失与恢复有去向 | 逐来源／逐记录列出失败、部分、待补、公开受限、上游不存在字段及待人工核验项；验证重试／补采后重新验收，而非仅清除错误标记 |

合法的“当前无公开招标”需要最新、完整的上游扫描证据。不能为了满足“每个辖区至少有一条”的表面指标创建虚假或过期招标；也不能以空结果直接证明该辖区已完成核验。

## 执行与报告门禁

1. 运行相关单元、SQLite/MySQL 集成和浏览器流程，覆盖州、市、county 的正常、缺失正文、部分分页、错误归属、过期、附件异常和重导入保护场景。mock 用于验证行为，真实数据可靠性另以原始来源证据验收。
2. 在被测数据集上执行既有风险检查及全来源质量报告，并核对来源执行账、列表覆盖和实际招标。现有州级检查不能代替市／county 验收；当前工具未覆盖的维度明确记为未验证，补充逐来源检查证据。
3. 对声明完整的范围进行清单与唯一 ID 对账；按平台及辖区分层复核原始正文和文件。抽样能验证所抽样内容，不能证明全量无遗漏。
4. 每次报告保留下面的矩阵及缺口明细。缺失、部分、过期、身份不明或无完整性证据的来源阻断相应范围的整体数据质量通过结论。检查未执行则填写“未验证”，不得填写“通过”。
5. 有失败时可以声明已执行的代码检查结果或测试执行已完成，但必须同时明确“整体数据质量未通过／尚未验证”。修复或补采后用新证据复验。

| 层级 | 目标机构／来源数 | 已验证完整可靠 | 缺失／部分／过期 | 未验证 | 证据与最终结论 |
| --- | --- | --- | --- | --- | --- |
| 州 state | 必填 | 必填 | 必填 | 必填 | 必填 |
| 市 city | 必填 | 必填 | 必填 | 必填 | 必填 |
| 县／郡 county | 必填 | 必填 | 必填 | 必填 | 必填 |

外部站点变化可能使数据暂时不完整。测试必须检测并阻断不合格结果，不能承诺未经证据验证的绝对完整。离线夹具、历史快照、HTTP 200、健康检查和 CLI exit 0 均不能独立证明当前真实数据完整可靠。
